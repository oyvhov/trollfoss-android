Reis til Skyøya med sengballongen! Trollfoss får 20 nye interaktive leiker, nivå 4–6, kunst, kjæledyr, band og fest. Husbygging, lager, spelarval og oppdragshjelp er enklare å bruke. Figurar, klede, hus og framgang blir bevarte når du oppdaterer.

- Prøv portal, kran, tandem, dokketeater, transportband og fleire leiker. Nivå 4–6 gir fire nye gåver kvar.
- Lag stempelbilete og tapet, dyrk eple, reparer lys og finn hemmelegheiter i kvardagsting.
- Venner kan klemme, gi high five og halde hender. Kjæledyr og ein levande bamse kan bli med, og venner kan spele i band og kome på fest.
- Bygg og finn rett rom lettare. Riv og Angre fungerer med tydelege knappar, også på mobil.
- Set ein spelar på pause i sekken og hent tilbake same figur med portrettet. Kartretur held laget der det var.
- Lager har tydeleg tilbakehenting, og foto får førehandsvising utan knappar eller namneskilt.

Installer APK-en over den gamle appen. Du treng ikkje avinstallere Trollfoss.

Nivå 7–10 er framleis planlagde og er ikkje med i denne utgåva.
