Meir leik og tydelegare framgang! Nivå 1–3 gir åtte nye interaktive leiker. Oppdrag viser kva barnet kan gjere og kva som blir låst opp. Pumpe, vennekamera, eit tog å reparere, putehytte og trillevogn gir meir å utforske. Angreknappen tek vare på opptente merke.

- Bobler, vindmølle, vennebuss og putekastar på nivå 2.
- Klinkekulebane, vaskbar fargesprøyte, miniheis og popcornvogn på nivå 3.
- Kameraet lagar portrett som kan flyttast og leggjast på lager.
- Tre frivillige eventyr, fleire tingshandlingar og reaksjonar frå venner.
- To handtak på trillevogna for samarbeid, med hjelp for eitt barn.
- Større romval og førehandsvising når barnet byggjer huset.
- Gamle figurar, klede, ting og opptente merke blir bevarte ved oppdatering.

Dette er dei første ti av 25 planlagde løft. Høgare nivå kjem i seinare utgåver.
