### Avgrensing ved emulatorgrafikk

Dei eigne Windows-emulatorane gav fleire fokus-ANR-ar med venting i Android si native teikning.
Linux/KVM lét heile den praktiske flyten gå gjennom. Ved første opning rett etter Android-installasjonen
vart likevel éin fokus-ANR registrert, kl. 18:21:18 lokal tid. Testen sende appen i bakgrunnen medan
oppstartsteikninga framleis gjekk. Trådsporet viser at hovudtråden ventar i `HardwareRenderer.setStopped`,
med RenderThread i emulatorbiblioteket `libEGL_emulation` / `qemu_pipe_read` / `glCreateProgram`.

Etterfølgjande oppstart og navigering fungerte. Som avgrensa kontroll vart den same installerte APK-en
køyrd med `debug.hwui.renderer=skiavk` på den eigne eininga; Skia/Vulkan vart stadfesta med `gfxinfo`.
Kaldstart i begge format og bakgrunn/framgrunn gav ingen nye ANR-ar. Loggen bevarer den eine tidlegare
hendinga. Dette peikar mot emulatorgrafikken, men grunnårsaka er ikkje endeleg fastslått. Det er ikkje
ein stadfesta retting i appen eller ein kontroll på fysisk eining. Tidene frå `am start -W` (om lag
1,4–1,9 sekund) må ikkje tolkast som måling av fullteikna skjerm eller jamn biletfrekvens.

## Publisering og ekte oppdatering

Kladden hadde nøyaktig éin APK og dei tre tekstvedlegga `SHA256SUMS.txt`, `SOURCE_COMMIT.txt` og
`mapping-v1.16.0.txt`. Storleik, opplastingsstatus og GitHub-digest vart sjekka før publisering som
vanleg siste utgåve. Den offentlege release-lista og `/releases/latest` vart kontrollerte utan token.
Ein separat nedlasting hadde same SHA-256 som den arkiverte APK-en.

Privat testutgåve av same kjelde, kode 20 / namn 1.15.0 og same nøkkel, vart installert først. Ho vart
aldri publisert. Det vanlege 1.16.0-bygget vart bygd opp att etter versjonsoverstyringa.

Den verkelege flyten vart gjennomført frå Kart → foreldreporten → Appoppdateringar → Sjekk no →
Last ned oppdatering → Installer oppdatering. Løyve for Trollfoss vart gitt på den eigne testeininga,
og Android sin UPDATE-knapp vart brukt. Installeraren viste «App installed».

Etterpå stadfesta Android kode 21 / namn 1.16.0 og `com.android.packageinstaller` som installatør.
SHA-256 av den faktisk installerte `base.apk` er identisk med den publiserte APK-en.

Lagringa før og etter vart samanlikna: alle 359 objekt-ID-ar, alle ting, alle figurnamn/utsjånader,
Sander si fulle lagring, den flytta bamsen, spelarval, innstillingar, møblar, lager, besøk og framgang
er bevarte. Den einaste skilnaden mellom figurkroppane var Rumle sine x/y-koordinatar etter vanleg
automatisk gåing før kartet vart opna; rå samanlikning og forklarande detaljkontroll er begge lagra.
