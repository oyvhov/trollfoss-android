Vel éin, to eller fleire faste spelarar som følgjer med mellom rom og stader, med same utsjånad, klede og ting. To barn kan leike med kvar sin figur samtidig på nettbrettet.

Dra møblar frå Møblar og Lager rett inn i rommet. Legg figurar bort med Venner → Her no → Legg i sekken, og hent dei tilbake seinare.

- Vel spelarar ved start eller seinare frå Kartet og romma. Spelarvalet blir lagra.
- Lag ein ny figur, eller endre utsjånad og klede på ein vald spelar undervegs. Hald inne spelarportrettet for å opne figurverkstaden.
- Spelarane følgjer med på reiser, gjennom trappene og ved rombyte. Ein annan finger kan ikkje overta ein figur som allereie blir halden.
- Figurar i sekken beheld klede og ting også etter omstart. Ein figur som blir lagd bort, sluttar å følgje etter automatisk og kan veljast som spelar igjen.
- Storhusmøblar får rett teikning når dei blir sette ut andre stader, også på Stranda.

Den eksisterande verda, huset, figurane og samlingane blir bevarte ved oppdatering.
