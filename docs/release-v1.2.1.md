Finare hus, levande kart og lettare møblering. Kartet følgjer årstidene og får pynt til jul, påske og graskartid. Møbellageret oppdaterer seg straks, og møblar glir på plass ved veggar og kvarandre. Husa har fått takbjelkar, loft og små dyr på nettbrett. Jamnare bilete i travle rom.

- Møbelkatalogen viser tinga i små utstillingsrom, og lageret har enklare kort og eit tal på knappen.
- Trykk på tomme felt i møbelmenyen flyttar ikkje møblar bak menyen.
- Ting som blir sleppte like ved eit bord eller ei hylle, får hjelp til å lande på flata.
- Mitt hus viser dører, vindauge og etasjar på kartet. Butikken har fått ein finare fasade.
- Nettbrett med Android 16 får betre støtte for liggjande skjerm.

Installer oppå den gamle Trollfoss-appen for å ta vare på figurane og husa. Android 8.0 eller nyare. Utgåva er signert med den same Trollfoss-nøkkelen som før.
