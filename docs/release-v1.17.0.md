Vagstaddalen har fått foss, strand og badeliv! Ta på badeklede, bad i elva og køyr ein liten gummibåt med plass til to. Fisk ved fossen, steik fangsten på bålet og finn fleire detaljar i tre, steinar og hytta. Figurar, eigne endringar, klede, ting, hus og framgang blir bevarte.

- Ny foss over to fjellhyller på høgresida, med skum, vassprut og fiskar i kulpen.
- Ei lita elvestrand med sandslott, bøtte, spade, badeball og badering.
- To slags badeklede som kan dragast på figurane. Dei gamle kleda kan takast på att.
- Ein liten gul gummibåt med to sitjeplassar og køyrepiler. Båten stoppar ved elvebreidda.
- Ny fiskeplass og bål på høgre breidd, med pølse og marshmallow. Fangsten kan steikjast.
- Fleire detaljar i bjørker, gran, mose, bregner, steinar og hytteveggar.
- Dei nye tinga kjem éin gong i gamle spel. Flytta og pakka ting blir bevarte.
