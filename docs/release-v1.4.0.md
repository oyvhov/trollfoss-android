Trollfoss har fått nye personar og ein større figurverkstad med 18 frisyrer, augefargar og glidebrytarar for hår og auge. Reis med ei stor seng under ballongen. Les bøker, ring venner, kast ball og prøv fleire ting saman. Lager fungerer også på stranda, og båt, radiobil og ubåt kan styrast.

- Fleire ansikt, nasar, smil, klede, mønster og morosame detaljar. Sjå endringane medan du lagar figuren.
- Tunnelen frå Trollhola til Storhuset er behalden som ein tydeleg merkt hemmeleg tunnel.
- Tannpuss, kosing med bamse, kiling og instrument som får venner til å danse. Trykk på tingen i handa for å bruke han igjen.
- Bygg sandslott med spade og bøtte, styr TV-en med telefonen og sprett ballar på trampolina.
- Set ut lagerting i alle stader som har golv. Rydd lageret éin ting om gongen og angre sletting medan appen er open.
- Fleire møbelplassar og køyring med piler og stopp. Ubåten kan stige og dykke.

Eksisterande figurar, namn, klede, ting og framgang blir bevarte ved oppdatering.
